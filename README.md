# Bluebox Homebrew tap

The [Homebrew](https://brew.sh) tap for the `bluebox` command-line interface of [Bluebox](https://bluebox.ai).

## Install

For the supported ways to install the CLI, see the [CLI reference](https://docs.bluebox.ai/cli).

## Contributing

The formula in this repository is generated by the Bluebox release workflow on every release. Pull requests are not accepted.

## Help

To report a problem or get help, see [Get help](https://docs.bluebox.ai/getting-help).
