# Bluebox Homebrew tap

The [Homebrew](https://brew.sh) tap for `bluebox`, the command-line interface of [Bluebox](https://bluebox.ai).

## Install

```bash
brew install bluebox-hq/tap/bluebox
```

For the other ways to install the CLI, see the [CLI reference](https://docs.bluebox.ai/cli).

## Contributing

The Bluebox release workflow generates the formula in this repository on every release, so this repository does not accept changes to it.

## Help

To report a problem or get help, see [Get help](https://docs.bluebox.ai/getting-help).
